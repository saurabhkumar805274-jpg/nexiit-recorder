macOS: first launch shows a warning. This build is unsigned, so Gatekeeper blocks it the first time. Right-click the app and choose Open, or run xattr -dr com.apple.quarantine /Applications/Nexiitt\ Recorder.app in Terminal.
Verify your download. Each platform ships a checksum file. After downloading, run shasum -a 256 -c SHA256SUMS-<platform>.txt to confirm the file is intact.
